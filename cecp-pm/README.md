# 主日下午聚会

独立的静态网页，按日期读取 `weekly/YYYY-MM-DD.json`。当前仓库中的 `weekly/latest.json` 指向首页显示的那一周；旧日期可用 `?date=YYYY-MM-DD` 打开。

## 本地预览

在 `cecp-pm` 文件夹运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。部署到 GitHub Pages 等静态托管时不需要构建。

## 每周更新

1. 复制上一周的 JSON，命名为本周日期，并修改 `date`、流程和各项内容。
2. 内容核对后，把 `weekly/latest.json` 的日期改成本周日期。
3. 在文件夹中运行 `node tools/sync-content.mjs`，同步双击打开时使用的内容文件。若旁边有原站的 `songs` 文件夹，旧歌名匹配表也会顺便更新；正常加歌不需要编辑它。
4. 用 `?date=YYYY-MM-DD` 检查本周页面。未填写的诗歌、读经、献诗和证道会显示同工正在准备中的提示；通知为空时显示「本周暂无通知」；直播回放未提供链接时显示「本周暂无直播回放」。

主要字段：`schedule` 是时间表，每项的 `section` 指定对应正文环节：`prayer`、`worship`、`reading`、`sermon`、`dismissal`。页面用这一份数组生成总览和正文，因此改动顺序或时间只需修改一次。`reading` 是读经经文；`sermon` 可填 `title`、`speaker`、`ref`、`outline`（字符串数组）；`songs` 是敬拜诗歌，`offeringSongs` 是读经后的献诗；`announcements` 直接写成字符串数组，例如 `["聚会后请同工留下开会"]`；`replayUrl` 是直播回放链接；`invitation` 是聚会邀请文字。外链应使用 HTTPS。

2026-09-20 已录入五段流程、诗篇 37 篇读经、培训通知，以及用户确认的「在基督根基上成长建造」和四点大纲。证道经文为哥林多前书 3:1–23，讲员从服事表同步。按原聚会程序录入了三首敬拜诗歌及一首献诗；目前原站曲库没有这四首的对应条目，所以页面只显示歌名。回放地址尚未提供，回放栏目显示暂无回放。

本文件夹可作为独立仓库的根目录发布。正式部署后，网站帖子可嵌入页面，或直接链接到该周的 `?date=` 地址。

## 服事安排

页面从 `index.html` 中的 `data-api` 读取现有服事安排接口，与原网站服事表共用数据。按帖子日期的年份、月份、当月第几个主日及「主日下午」筛选，只显示已填写的岗位。9 月 20 日对应 2026 年 9 月第三周。页面不会把其他聚会或其他年份的安排补进来；查不到时显示尚未公布，网络失败时可以重新加载。

直接双击打开 `index.html` 或 `preview.html` 也能显示已同步的每周内容。服事表、经文和曲库依旧需要网络。页面的标题、栏目、按钮和页脚均使用中文；排班表中录入的姓名保留原文。

## 与青年页共用的功能

- 以后加曲库诗歌，只在本周 JSON 的 `songs` 或 `offeringSongs` 中填原站歌曲文件名（不带 `.json`），例如 `"songs": ["nengbuneng", "endianzhilu"]`；`{"id":"nengbuneng"}` 和 `{"title":"nengbuneng"}` 也可以。页面直接读取独立仓库 `CYE04/songs` 根目录的 `<id>.json`（`https://cye04.github.io/songs/<id>.json`），显示曲库提供的歌名、播放器、同步歌词、移调、和弦查看、节拍器、荧光笔、歌谱放大和图片导出，**不需要修改 `song-catalog.js`**。已有歌名匹配表仍可识别其中的中文歌名；新歌若只填中文歌名而表中没有对应记录，则只显示歌名。重名版本请填文件名。
- 只有歌名、没有曲库资料的诗歌会显示「复制歌名」按钮，方便到曲库搜索或转发歌名。
- 可以给 `songs` 或 `offeringSongs` 填 `title`、`lyrics`（歌词）、`mp3`（音频）、`scoreImg`（歌谱图）和 `url`（资料链接）。只有明确填写的资料才会出现。同名歌曲有多个版本时请改填曲库编号 `id`。
- `reading` 和 `sermon` 添加 `book`（经卷序号）、`chapter`（章），以及需要时的 `start`、`end`（节），即可展开中文经文、查阅其他章、调整字号、大字阅读及复制经文。诗篇的经卷序号是 19，哥林多前书是 46。
- `replayUrl` 支持常见的视频分享、观看或嵌入链接，自动转为页面内播放器；直接视频文件也可播放，其他链接显示打开按钮，不自动播放。
- 当天流程提示按 `Europe/Rome` 时间计算，休息间隔和旧帖子不显示「正在进行」。流程里的 `roles` 可填服事表岗位键，在环节下同步显示负责人。
- 正文环节按照聚会时间表逐段排列：祷告会、敬拜与记念祷告、读经与献诗、证道、祝福祷告散会。各环节标题上方显示起止时间，点击上方总览可以跳到对应环节。页面不显示装饰性序号。
- 支持复制本周链接、打印程序、失败后重新加载。没有填写的诗歌内容不会显示。

`index.html` 的 `data-song-base`、`data-song-engine`、`data-media-base`、`data-bible-api` 指定共用资源地址。相对音频地址会解析到教会网站；本页面可独立部署，但曲库、经文和排班需要网络访问。乐谱中的调号与和弦字母属于音乐记号，保留原样。

## 功能预览与检查

`preview.html` 使用 `examples/full.json` 展示三首现有曲库诗歌与回放工具，其中一首按曲库编号读取、两首按歌名匹配；页首标明「功能预览」，与正式每周数据分开。示例诗歌和回放来自现有青年聚会资源，不是当天歌单。

运行 `node --test tests/core.test.cjs` 检查跨年排班匹配、第五个主日、重复记录、意大利夏冬令时、流程间隔、歌名复制及回放链接处理。浏览器可检查本周页的真实名单与经文，并在功能预览页操作移调、歌谱下载和播放控件。

## 放到 Halo 文章

网站地址已是 `https://cye04.github.io/cecp-pm/`。在 Halo 新建当周文章，标题例如「2026 年 9 月 20 日下午聚会」。换周时只改日期，不必复制整页内容。

如 Halo 编辑器支持 HTML 内容块，可在文章里放入下面这段。与 Youth 引擎一样，采用原生直接挂载（无 iframe），全屏歌谱遮罩能完整覆盖整个手机/电脑屏幕，流程直达原生平滑滚动，并自动跟随 Halo 的深浅色主题：

```html
<div id="cecp-pm" data-date="2026-09-20"></div>
<script src="https://cye04.github.io/cecp-pm/embed.js?v=20261004-no-iframe"></script>
```

换周时把 `data-date` 和链接中的日期一起改成新日期。Halo 文章只放这段嵌入代码；每周流程、诗歌、通知和回放仍在本仓库的 `weekly/YYYY-MM-DD.json` 更新，服事人员由排班接口读取。嵌入效果取决于 Halo 主题的文章宽度，发布前在手机上预览。
