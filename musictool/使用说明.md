# 一、简谱编辑器（重点）

版本 v3.1。整首歌的结构是 **段落 → 行 → 格子（seg）**。每个格子里有三样东西，从上到下：**和弦** → **简谱音符** → **歌词**。你在左下角点一个格子选中它，然后用右边的键盘往里填音符，在格子的输入框里打歌词和和弦。

## 1. 界面速览

- **顶栏标签**：导入 / ⌨ 填歌词 / ⚑ 检查 / ⇔ 对齐 / 预览 / 工具 / 代码
- **上半区**：预览（所见即所得的简谱）、工具、代码（元数据 + 导出）三选一
- **中间状态栏**：当前选中位置、音符总数、当前八度/时值/附点/延长号/房子线、选区、剪贴板
- **左下段落区**：所有段落和格子，点格子进入编辑；顶部有搜索框（⌘F）
- **右下键盘区**：所有音符和符号的输入按钮 + 双行简谱面板
- **☑ 严格对位**：左上角的开关，勾上进入「严格对位」模式（见 §11）

## 2. 快速上手（6 步）

1. **填信息**：点「代码」标签，填歌名、艺人、原调、拍号、BPM（**ID = 导出文件名**）。
2. **建段落**：左下点「+ 新增段落」，给段落起名（主歌/副歌/Bridge…）。
3. **选格子**：点段落里的一个格子，它会高亮，状态栏显示位置。
4. **填音符**：右边键盘先选 **八度** 和 **音值**，再点数字 **1–7**（或 `0` 休止）。要延音、附点、小节线、连音就点对应按钮。
5. **填词加弦**：直接在格子的歌词栏输入歌词、和弦栏输入和弦（如 `C` `Am` `G7`）。
6. **导出**：回「代码」标签 →「复制完整 JSON 文件」，存成 `ID.json`。

## 3. 音符输入详解

选好格子后，右边键盘从上到下：

- **八度**：低2 / 低1 / **中** / 高1 / 高2（快捷键 `↑ ↓` 升降八度）。渲染时高八度在数字**上面加点**，低八度在**下面加点**（最多 2 点）。
- **音值**：全 `Q` / ½ `W` / ¼ `E`（四分＝1拍，默认）/ ⅛ `R`（八分，数字下加**一条**下划线）/ ¹⁄₁₆ `T`（十六分，**两条**下划线）。**先选音值再点音符**。
- **输入模式**：**插入 `I`**（在光标处插入）/ **覆盖 `O`**（替换当前音）。
- **音符**：`1 2 3 4 5 6 7` 七个音（Do–Si），`0` 是休止符。

## 4. 基础符号

| 按钮 | 作用 | token | 快捷键 |
|---|---|---|---|
| — 延音 | 音延长一拍 | `-` | `\` |
| · 附点 | 附点音符（时值 ×1.5），开关 | `·`(中点 U+00B7，**不是句号**) | `,` |
| 𝄐 延长号 | 自由延长记号（挂在音符上方），开关 | 音符后缀 `^`（如 `3^`） | `F` |
| ␣ 空格 | 插入占位空格（对齐用，不发声，占 1 个数字宽） | `sp` | `Space` |

> **延长号 `^` 是「音符后缀」**（写在数字后面，如 `5^`）。它跟 §6c 的**断梁 `!`** 是两个不同的东西，别混。

## 5. 临时记号（升降号）

先点记号，再点音符，记号就加在那个音的**前面**：

- ♯ 升 `K`（`#5`）／ ♭ 降 `J`（`b5`）／ ♮ 还原 `H`（`=5`）／ 清除
- 实际歌里基本只用 `#`。

## 6. 线条与结构

键盘里「线条与结构」分成三组：**小节线·反复** / **导航记号** / **连音·连音符·拍号**。

### 6a. 小节线 & 反复记号

| 按钮 | token | 样子 | 快捷键 |
|---|---|---|---|
| 小节线 | `|` | 一条细线 | `B` |
| 双小节 | `||` | 细 + 细（段落分隔） | `M` |
| 终止线 | `||/`（=`|]`） | 细 + 粗（全曲结束） | |
| 反复开 | `|:` | **粗 · 细 · 两点** | |
| 反复结 | `:|` | **两点 · 细 · 粗** | |
| 反复段 | `|:|` | 点·细·粗 · 粗·细·点（既结又开） | |

> 记法：**粗线永远在外侧**。反复开的粗线在左、反复结的粗线在右，两点靠近音符那侧。

### 6b. 导航记号（Fine / D.C. / D.S. / Coda / Segno）

点按钮就自动插入、渲染。都放在小节线的位置：

| 按钮 | token | 渲染 |
|---|---|---|
| Fine | `fine` | 终止线 + 下方斜体 **Fine** |
| D.C.（da capo，从头反复） | `dc` | 双线 + 下方 **D.C.** |
| D.S.（dal segno，从记号反复） | `ds` | 双线 + 下方 **D.S.** |
| Coda（尾声记号 ⊕） | `coda` | 竖椭圆 + 十字穿出的 ⊕ 符号 |
| Segno（反复记号 𝄋） | `segno` | 官方 𝄋 字形 |

### 6c. 断梁 `!`（新）

| 按钮 | token | 作用 |
|---|---|---|
| ! 断梁 | `!` | 让前后两个带下划线的音符**不连成一条梁**（小断开），**只在严格对位模式生效** | 快捷键 `!` |

- 用途：两串八分音符本来会连成一梁，中间放个 `!` 就断成两梁。
- **它不占音位、不用写 `@`**（见 §11）。
- ⚠️ 断梁是**独立 token `!`**；延长号是**音符后缀 `^`**（如 `3^`）。两者不冲突。

### 6d. 连音 · 连音符 · 拍号

| 按钮 | token | 作用 | 快捷键 |
|---|---|---|---|
| ( ) 连音 | `( … )` | 圆滑线，把选中的一串音连起来，开关 | `[` / `S` |
| ⌒ 双连音 | `~` | 连接相邻两个音 | `N` |
| ⌒² 跨音连 | `~2` / `~3` | 跨过中间 1 个 / 2 个音连接 | `⇧N` |
| 跨行连 | `([ … ])` | 连线跨越小节线/跨格：一格末尾 `([`，下一格开头 `])` | `]` / `X` |
| 拍号记号 | `[ts:3/4]` | 在谱中插入变拍号 | |
| 3连 / 5连 | `{3 … }` / `{5 … }` | 三连音 / 五连音括号 | |

## 7. 房子线（反复的 1./2. 括号）

- **1. 房开** `[v1` / **2. 房开** `[v2`：第一、第二房子线开始
- **自定义房** `[v:1.3]`：自己填数字的房子线
- **房结** `]v`：房子线结束
- **自定义Tok**：手动插入任意 token（也可输双行 `1/5`）

## 8. 双行简谱（上下两行叠着的音）

右下角「双行简谱可视化输入」面板：

1. **上行**、**下行** 各自点数字填音（`sp` 占位、`-` 延音）。
2. 选时值：4分 / 8分 / 16分，可加附点、延长号。
3. 看「预览 token」（如 `1/5` = 上 1 下 5）确认无误，点 **插入双行**。
4. 空的一边默认补 `sp`（`/5` = 上空、下 5）。

（快捷键 `/` 快速跳到这个面板。）

## 9. 格子操作

| 按钮 | 作用 | 快捷键 |
|---|---|---|
| ⌫ 删除 | 删掉选中的音/格 | `Bksp` |
| ↩ 撤销 | 撤销上一步 | `⌘Z` |
| ✕ 清空 | 清空当前格的音符 | |
| ⬡ 复制格 | 复制整格（和弦+音符+歌词） | `Alt+C` |
| ⬡ 粘贴格 | 粘到后面 | `Alt+V` |
| ⬡ 覆盖格 | 覆盖当前格 | `Alt+R` |

## 10. 歌词与和弦

- **单格填**：点格子，在它的歌词栏 / 和弦栏直接打字。
- **批量填歌词**：顶栏「⌨ 填歌词」，把整段歌词一次贴进去，按音符自动分配（省得一个字一个字点）。
- 和弦写常见写法即可：`C` `Am` `G7` `F#m` `C/G`…（导出/显示时会自动移调，斜杠低音也移调）。
- **括号和弦** `(C/G)`：括号是「可选/经过和弦」的意思，里面的和弦照样识别、移调。

## 11. 严格对位模式（align:"strict"）—— 重点新功能

左上角勾选 **☑ 严格对位** 进入。普通模式靠 `sp`、`ㅤ`、空格手动对齐；严格模式让**和弦、歌词按「音位」跟音符一一对齐**，好写好控。导出时会自动写 `"align":"strict"`，musiclib/青年/投影三处都走严格分支渲染。

### 11.1 什么是「音位」

一个**音位** = 简谱串里一个真正占位置的单元。规则：

- **算音位**：音符 `1`–`7`、休止 `0`、增时线 `-`、占位 `sp`、双音 `1/5`（上下算一个）。
- **不算音位**：小节线 `|`/`||`/…、连音括号 `( )`/`([ ])`、连音符 `~`、连音符括号 `{3 }`、房子线 `[v1 ]v`、拍号 `[ts:..]`、**断梁 `!`**、导航记号 `fine`/`dc`/`ds`/`coda`/`segno`、分隔符 `/`。

和弦、歌词就是**跟音位一一对齐**：第 1 个对第 1 个音位，第 2 个对第 2 个……

### 11.2 `@` = 这个音位上没有内容（空位）

某个音符下面没有歌词 / 上面没有和弦，就写 `@` 占住那个位置。例：

```
n     : 1  2  3  3  5  6
和弦  : C  @  @  @  G  @      ← 只有第1、5个音有和弦
歌词  : 我 爱 你 @  主 啊      ← 第4个音是拖腔（无字），写 @
```

`@` 渲染成**透明空白**（那个音下面/上面空着），不会显示字符。

### 11.3 歌词可以「直接连写」（省去每字敲空格）

严格模式下歌词**只要连着写**，中文自动每字一个音位：

- `我爱你耶稣` → 我 / 爱 / 你 / 耶 / 稣（5 个音位）
- **拖腔 / 没词的音写 `@`**：`我爱@你` = 第 3 个音是拖腔
- 空格可有可无，老的「每字空格」写法结果完全一样，不冲突

### 11.4 标点自动「粘」前一个字，不占音位

歌词里的 **`，。、；：？！…（）「」" ",.;:?!()` 等全套中英标点**会自动贴到**前一个字**上，**永远不占音位**，也不用管空格：

- `你，主啊！` → 你，/ 主 / 啊！（3 个音位，逗号和叹号跟着字）
- 渲染时标点做**悬挂**处理：字仍居中对齐音符，标点挂在字的右边、不撑宽格子、不推歪后面的字。
- 例外：`-`（连字号/增时线）不当标点。

### 11.5 英文 / 拼音用空格断音节

英文一个音节对一个音，靠**空格**分：

- `Je sus loves me` → 4 个音位（Je / sus / loves / me）
- `Jesus`（不分）→ 1 个音位（整词唱在一个音上）

### 11.6 和弦的 `@` 也能内联（免空格）

和弦栏跟歌词一样，`@` 可以**贴着写、不用敲空格**：`C@@@G@` 等于 `C @ @ @ G @`。两个**真和弦之间**（如 `Am7` 跟 `G`）仍用一个空格分开——因为和弦是多字母的，跟英文歌词一样不能逐字母拆。逗号叠和弦 `C,G` 也照旧整体保留。

### 11.7 一个音位叠两个和弦

和弦栏一个位置想放两个和弦，用**逗号**分：`C,G`（第一个 `C` 在下、`G` 在上）。

### 11.8 检查

- 音位数和歌词/和弦 token 数对不上，**只给警告、不拦保存**，并指出「第几个音位起对错了」。
- 存盘时（严格模式）会自动在尾部补齐 `@`。

## 12. 草稿自动缓存（防误触丢内容）—— 新

简谱编辑器现在会**自动把你正在编辑的内容存进浏览器**，防止手滑/误触「返回上一页」把辛苦填的东西弄丢：

- **自动保存**：边编辑边存，切走 / 隐藏 / 离开页面那一刻也会立即再存一次。
- **回来自动恢复**：重新打开简谱编辑器时，若有上次未保存的草稿，会自动把内容（音符、歌词、和弦、信息）全部恢复，顶部弹一条 **「已恢复上次未保存的编辑 · 清空重来」**。想从头开始就点「清空重来」。
- **轻拦截返回**：不小心按「返回上一页」时会先吸收一次并提示「已存草稿 · 再返回一次即退出编辑」，配合自动恢复双保险。

> 注意：这是浏览器本地缓存（同一台设备、同一浏览器）。真正保存作品还是要「复制完整 JSON 文件」存成 `.json`。

## 13. 检查 · 对齐 · 整理

- **⚑ 检查**：核对每行的音符数、歌词数、和弦数对不对得上，出错会提示第几个位置。
- **⇔ 对齐**：预览行两端对齐（**只影响预览排版，不改数据**）。
- **工具 → 整理格式**：规范化数据格式。

## 14. 试听与试移调（工具标签）

- **播放当前行 / 播放整首 / 停止**：用合成音色试听，检查音对不对。
- **试移调**：填原调和目标调，点「预览」看移调后的样子（**只预览，不改原数据**）。

## 15. 元数据与导出（代码标签）

先把信息填全（导出时按固定顺序输出全部 16 个字段）：

| 字段 | 说明 | 默认 |
|---|---|---|
| ID | **文件名**，如 `zmzq-shunfu` | `song-id` |
| 歌名 title / 艺人 artist / 副标题 sub | 显示信息 | 空 |
| 原调 origKey | 如 `A` `Bb` | `C` |
| 拍号 timeSign / BPM | 如 `4/4` / `72` | `4/4` / `72` |
| YouTube / MP3 | 链接或文件名 | 空 |
| 封面 cover / 歌词 lrc / 乐谱图 scoreImg | 填文件名即可，默认前缀 `https://cecpadua.github.io/resouces/…` | 空 |

导出两种：

- **复制 sections 数组**：只要谱面数据
- **复制完整 JSON 文件**：整首歌完整 JSON（存成 `ID.json` 用这个）

导入：顶栏「导入」，把 `sections` 数组或 `var SECTIONS = […]` 或整段 JSON 粘进去（导入含 `"align":"strict"` 会自动开严格模式）。

## 17. 简谱 token 速查（`n` 字段里长什么样）

`n` 是**空格分隔**的 token 串，每个单元一个 token。写法顺序：`[升降号]数字[八度][·][下划线][^]`。

| 写法 | 含义 |
|---|---|
| `1`–`7` | 音符 Do–Si；`0` 休止 |
| `1'` `1''` | 高一 / 高二八度（撇号，点在上）；`1,` `1,,` 低八度（逗号，点在下） |
| `1_` `1__` | 八分（一条下划线）/ 十六分（两条） |
| `#5` `b5` `=5` | 升 / 降 / 还原（前缀） |
| `1·` | 附点（中点 U+00B7，时值 ×1.5） |
| `3^` | 延长号（音符后缀 `^`） |
| `-` | 增时线（延长一拍，自成一个 token） |
| `sp` `sp_` `sp__` | 占位空格（0 拍，对齐用；带下划线可续梁） |
| `|` `||` `||/`(=`|]`) | 小节线 / 双小节 / 终止线 |
| `|:` `:|` `|:|` | 反复开（粗细点）/ 反复结（点细粗）/ 反复段 |
| `fine` `dc` `ds` `coda` `segno` | 导航记号：Fine / D.C. / D.S. / Coda⊕ / Segno𝄋 |
| `!` | 断梁（严格模式，不占音位） |
| `( … )` | 圆滑线（连音） |
| `([ … ])` | 跨行/跨小节连线（一格 `([` 起、下一格 `])` 收） |
| `~` `~2` `~3` | 双连音 / 跨 1 音 / 跨 2 音连线 |
| `{3 … }` `{5 … }` | 三连音 / 五连音 |
| `[v1 … ]v` | 第 1 房子线（`[v2` 第 2，`[v:1.3]` 自定义） |
| `[ts:4/4]` | 谱中变拍号（也可用格子的 `timeSign` 键） |
| `1/5` | 双行简谱（上行 1 / 下行 5） |

> **不可见对齐符**：`ㅤ`（U+3164，韩文填充符）和 `{sp}` 是零宽/占宽的不可见对齐符，可出现在和弦或歌词里做微调，两者长期共存、原样保留、勿互相转换。（严格模式下优先用音位 + `@`，一般用不到。）

## 18. 歌 JSON 结构速览

```jsonc

  "id":"歌ID", "title":"歌名", "artist":"艺人", "sub":"副标题",

  "mp3":"…", "cover":"…", "lrc":"…", "youtube":"…", "scoreImg":"…",
  "align":"strict",              // 只有严格模式才有这行
  "sections":[
    { "name":"主歌", "lines":[
      // 一行 = 一串格子（数组）；副歌整行加粗用 { "b":true, "line":[…] }
      [ {"chord":"C","n":"1 2 3","lyric":"我爱你"}, {"chord":"","lyric":"｜"} ],
      { "b":true, "line":[ /* 加粗行的格子 */ ] }
    ]}
  ]
}
```

- **格子（seg）**：一定有 `chord` 和 `lyric`（可为空 `""`）；`n` **有音符才写**。可选 `lyric2`/`lyric3`/`lyric4`（第 2/3/4 段词）、`timeSign`（本格变拍号）。
- **小节线格子**：`chord:""`、`lyric` 放小节线符号（如全角 `｜`）、没有 `n`。
- **段落标签格子**：`{"label":"Chorus"}`（可选 `style`/`dx`），没有 chord/n/lyric。

# 二、歌词编辑器（LRC 打轴）

给一首歌配上「每句歌词在第几秒出现」的时间轴，导出 `.lrc`。

## 1. 打轴流程

1. **⬆ 上传音乐**：选一个音频文件。
2. **准备歌词**（几选一）：
   - **⬆ 上传歌词**：已有 `.lrc` 文件
   - **📄 上传文本**：粘纯文本歌词（每行一句，不用时间戳）
   - **🔍 查找歌词**：在线找
   - **📄 创建歌词**：直接一行一句打进去（会清空当前歌词）
3. **打轴**：点 ▶ 播放，每唱到一句就点那一句，把当前时间戳打上去。
4. **微调**：
   - **偏移**：整体提前/延后几秒（填秒数 → 应用偏移）
   - **同步滚动**：开/关跟随播放高亮
   - **+ 新增歌词**：在末尾补一句
5. **add info**：填歌手 / 歌名 / 专辑 / 制作，写进 LRC 头。
6. **⬇ 下载歌词** 导出 `.lrc`；**⬇ 下载双语LRC** 导出中英双语版。

## 2. 播放控制

- 进度条可拖动，▶ 播放/暂停，右边有音量滑块，左上显示当前时间 `[00:00.00]`。

# 小贴士

- 两个工具的教程可随时点右上角 **?** 重新看。
- 简谱编辑器边填边看「预览」最直观；填错用 `⌘Z` 撤销；内容会自动缓存，误触返回也能找回（§12）。
- 导出前先点 **⚑ 检查**，确认音符数、歌词数对得上，避免上线后错位。
- 用**严格对位**（§11）填的歌最好控——中文歌词直接连写、拖腔写 `@`、标点不用管，音位天生对齐。
- 导出的 `ID.json` 放进歌库后，musiclib / 青年页 / 投影 都能直接用。
